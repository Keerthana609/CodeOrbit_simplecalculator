# CodeOrbit_simplecalculator
A command-line calculator built in python as part of the CodeOrbit Tech python Programming Internship. It performs basic arithmetic operations like Addition, Subtraction, Multiplication, and Division based on user input
# CodeOrbit_Todolistapp
Numbered, easy-to-read task list display Add new tasks through simple input prompts Remove tasks by selecting their number Tasks automatically saved to and loaded from a text file (tasks.txt) Code organized into clear, reusable functions for each feature
# CodeOrbit_numberguessinggame
Random number generation within a defined range (1–100) Instructive hints after every guess to guide the player Tracks and displays the number of attempts taken to guess correctly Input validation to handle non-numeric or out-of-range guesses Loop-based replay so the user can play multiple rounds without restarting
